# ReelPage

ReelPage is a responsive creative-industry network prototype connecting filmmakers, writers, actors, producers and creative professionals.

## Live-ready
- Responsive UI for phone, tablet and desktop
- Supabase Auth with magic-link sign-in
- Supabase-backed profiles, projects, opportunities and connections
- Cinematic ReelPage dark/electric-blue design

The frontend uses the Supabase publishable key only; no service-role secret is exposed.
